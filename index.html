Try the whole platform locally

Run the full platform on a local kind cluster with three commands: KubeRocketCI Portal, Tekton, Argo CD, SonarQube, self-hosted GitLab, and Prometheus with Grafana. No cloud account needed.

What you need

  • Docker Desktop with 12 GB of RAM for the full stack (8 GB runs the core only)
  • kind, Helm, kubectl, and make
  • macOS (Apple Silicon or Intel), Linux, or Windows with WSL2
Read the walkthrough try-kuberocketci on GitHub Install on your own cluster
bash
$ git clone https://github.com/KubeRocketCI/try-kuberocketci$ cd try-kuberocketci$ make testbed# full stack ready in ~18–20 min

One golden path for engineers and AI agents

Agent-authored pull requests run the same review pipeline, quality gates, and RBAC as your engineers' changes. Agents read the results through the krci CLI as JSON.

  1. Review: Tekton
  2. Build: Kaniko
  3. Gate: SonarQube
  4. Publish: Nexus
  5. Deploy: Argo CD
krci CLI docs Daily ops with AI agents llms.txt
bash
$ krci sonar gate my-app --pr 42 -o json | jq '.data.projectStatus'{  "status": "ERROR",  "conditions": [    {      "metricKey": "new_coverage",      "comparator": "LT",      "errorThreshold": "80",      "actualValue": "64.2",      "status": "ERROR"    }  ]}# the same gate result a human pull request gets
